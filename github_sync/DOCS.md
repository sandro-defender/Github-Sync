# GitHub Sync

Home Assistant App that syncs folders with GitHub. Open **GitHub Sync** in the sidebar after the app is started.

Settings leads with **Connect with GitHub** — a zero-config OAuth device flow (built-in public GitHub CLI client, no OAuth App setup) — with a personal access token and a custom OAuth App (browser login, GitHub Enterprise) also available. The app checks for a newer version of itself in the background and offers a one-click **Update now** (installed through Home Assistant's update entity). See the repository [README](https://github.com/sandro-defender/Github-Sync) for scopes, OAuth App setup, mapping instructions, ignore rules, and safety notes.
